# 兩基地待辦追蹤

新竹社創基地 × 新竹青創基地共用的待辦時程頁。依週排列，標出今天、逾期與 7 天內到期的事項，可依基地篩選、打勾完成、新增與編輯。

- 網頁：`index.html`（GitHub Pages 靜態頁）
- 資料：Google 試算表，透過 `apps-script.gs`（Google Apps Script）讀寫
- 設定：`config.js` 填入 Apps Script 的 `/exec` 網址

## 第一次設定（約 5 分鐘）

1. 新建一個 Google 試算表（例如「兩基地待辦」）→ 上方選單「擴充功能」→「Apps Script」。
2. 把 `apps-script.gs` 的內容整份貼上，取代預設的程式碼，儲存。
3. 上方函式選單選 `setup`，按「執行」，依提示授權。完成後試算表會多一個「待辦」工作表，含 33 筆初始待辦。
4. （建議）左側「專案設定」→「指令碼屬性」→ 新增屬性 `EDIT_PASS`，值填你要的編輯密碼。沒設的話，任何拿到網址的人都能修改。
5. 右上「部署」→「新增部署作業」→ 類型選「網頁應用程式」；執行身分「我」；誰可以存取「所有人」→ 部署，複製 `/exec` 結尾的網址。
6. 打開本 repo 的 `config.js`，把網址貼進 `TODO_API_URL = "..."` 的引號中，commit。
7. repo 的 Settings → Pages → Branch 選 `main`、資料夾 `/ (root)` → Save。約 1 分鐘後網址會出現在同一頁。

## 使用

- 勾選即完成；點「編輯」改日期、負責人或刪除。
- 第一次修改會要求輸入編輯密碼，這台裝置會記住。
- 每 30 秒自動抓最新資料；也可以直接在 Google 試算表修改（日期格式 `YYYY-MM-DD`，done 填 `TRUE`/`FALSE`）。
- 修改 `apps-script.gs` 後，要到「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」才會生效。

## 電視牆 `tv.html`

大廳電視／投影用的全螢幕畫面，和待辦頁共用同一份 Google 試算表：

- 左側：逾期、今天到期、7 天內到期、完成率，以及「下一個截止」大卡。
- 右側：逾期與接下來 14 天的待辦，自動翻頁輪播。
- 底部：跑馬燈列出接下來的截止事項。
- 每 15 秒抓一次資料；有人新增、完成、改期或刪除待辦時，右上角會跳出通知卡。
- 點一下畫面進入全螢幕；每 6 小時自動重新整理一次。

網址參數（可選）：

| 參數 | 用途 | 例子 |
|---|---|---|
| `base` | 只顯示某個基地 | `tv.html?base=社創`、`tv.html?base=青創` |
| `poll` | 幾秒抓一次資料（最少 10） | `tv.html?poll=20` |
| `page` | 每頁停留秒數 | `tv.html?page=15` |
| `rows` | 每頁幾筆 | `tv.html?rows=5` |

## 月會 KPI 達成表 `kpi.html`

每月月會簡報用的「重點執行項目／年度目標／達成率／備註說明」表，社創、青創各一張。

- 資料在同一份 Google 試算表的「KPI」工作表（第一次開啟 kpi.html 時自動建立並匯入初始資料）。
- 點表格任一列即可修改；編輯密碼和待辦頁相同。
- 備註可用 `**粗體**`、`__底線__`，Enter 換行；達成率只打數字會自動補 %。
- 「下載圖片 PNG」：匯出目前基地的表格圖，直接貼進簡報。
- 「下載 Excel」：社創、青創各一頁，含 logo、配色、粗體與底線。
- 匯出用的函式庫放在 `lib/`（html2canvas 1.4.1、ExcelJS 4.4.0），logo 圖在 `img/`。
- 新增這個功能後，`apps-script.gs` 要重新貼上並部署「新版本」。
